# NisheshChauhan_Task(25)

## Summary

This project is a basic React e-commerce UI built for showcasing multiple sneaker products with an interactive shopping cart. It demonstrates product listing, cart functionality, quantity updates, and automatic total calculation using React state.

## What it Does?

- Displays a grid of sneaker products with image, name, and price.
- Lets users add products to the cart.
- Increases or decreases the quantity of each item in the cart.
- Automatically calculates the total bill in real time.
- Uses a modern, clean layout with a sticky header and responsive product grid.
- Implements the app using React and Tailwind CSS styling.

## How to Run?

1. Open the project folder:

```bash
cd nsc-25-basic-react
```

2. Install dependencies:

```bash
npm install
```

3. Start the React app:

```bash
npm start
```

4. Open the local development server in your browser, usually at:

```bash
http://localhost:3000
```

5. To create a production build:

```bash
npm run build
```
